### 目录结构
```txt

Project/
| 
├── include/ // 存放头文件 
│ └── student.h 
├── src/ // 存放实现文件 
│ └── student.cpp 
├── main.cpp // 程序主入口 
└── Makefile // 编译脚本
```

```txt

netDisk/
├── API/                // 接口定义目录：存放客户端/服务端通用协议与接口声明
├── client/             // 客户端实现目录：处理连接、命令发送与客户端逻辑
├── server/             // 服务端实现目录：处理监听、并发调度与业务处理
├── include/            // 公共头文件目录：存放全局与模块头文件
│   ├── client/         // 客户端模块头文件
│   └── server/         // 服务端模块头文件
├── config/             // 配置目录：存放客户端、服务端及业务配置
├── tests/              // 测试目录：存放功能验证与测试程序
├── tmp/                // 临时数据目录：存放运行期临时文件/示例数据
├── build/              // 构建中间产物目录：目标文件与依赖文件
├── bin/                // 可执行文件目录：编译后的程序输出
├── Makefile            // 项目构建脚本：统一编译、链接、清理入口
├── README.md           // 项目说明文档
└── clean.sh            // 辅助清理脚本

```
