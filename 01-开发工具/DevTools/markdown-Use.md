
## 标题语法
1. 使用`#`的数量表示标题级别，`#`+空格+文本 为一则标题，例如：

```
# 一级标题展示
### 三级标题展示
###### 六级标题展示
```

2. 使用`=`表示一级标题，使用`-`表示二级标题，例如：

```
一级标题展示
===========
二级标题展示
----------------
```

3. 注意：`#`与内容之间应该空格间隔，`-`或`=`一个与多个效果一样

## 段落语法

要创建段落，请使用空白行将一行或多行文本进行分隔。  
行尾两个空格可以实现换行  

```
第一行
空行(段落)
第二行
```

注意：避免使用空格或tab键来缩进段落  

## 换行语法

两个或多个空格进行换行，称为 结尾空格（trailing whitespace)<br>
还可以使用Html语法的`<br>`
```
第一行 双空格
第二行<br>
第三行
```

## 强调语法
加粗显示文本，请在单词或短语的前后各添加两个星号(`**`)或下划线(`__`)。  
斜体显示文本，请在单词或短语的前后各添加三个星号(`***`)或下划线(`___`)。  

**粗体**  
***斜体***

```
**粗体1**
__粗体2__
***斜体1***
___斜体2___
```

## 引用语法
要创建块引用，请在段落前添加一个 > 符号。  
多个段落的块引用:块引用可以包含多个段落。为段落之间的空白行添加一个 > 符号。  
嵌套块引用:块引用可以嵌套。在要嵌套的段落前添加一个 >> 符号。  

> this is a demo
>
>> demo
```
> this is a demo
>
>> demo
```


## 列表语法
有序列表  
要创建有序列表，请在每个列表项前添加数字并紧跟一个英文句点。数字不必按数学顺序排列，但是列表应当以数字 1 起始。
1. list1
1. list2
2. list3

无序列表  
要创建无序列表，请在每个列表项前面添加破折号 (-)、星号 (*) 或加号 (+) 。缩进一个或多个列表项可创建嵌套列表。
- list1
- list2
  - list2.1
  - list2.2
- list3

要在保留列表连续性的同时在列表中添加另一种元素，请将该元素缩进四个空格或一个制表符
- list1
- list2
    > hello
- list3.
    - list3.1

```
1. list1
1. list2
2. list3

- list1
- list2
  - list2.1
  - list2.2
- list3
```

## 代码语法
要将单词或短语表示为代码，请将其包裹在反引号 (`) 中。 
使用三个反引号可以表示多行代码块 
要创建代码块，请将代码块的每一行缩进至少四个空格或一个制表符。  

`code`

    代码块1

```
代码块2
```

## 分割线语法
要创建分隔线，请在单独一行上使用三个或多个星号 (***)、破折号 (---) 或下划线 (___) ，并且不能包含其他内容。  
为了兼容性，请在分隔线的前后均添加空白行。


***
---
___

```
第一行
***
第二行
---
第三行
___
```
