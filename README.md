- `.obsidian/`：Obsidian 工作区配置，不建议随意移动或删除。

## 后续建议

- 新笔记优先按主题放入现有分类，尽量不要继续堆在仓库根目录。
- 如果“智能康复系统”后续内容继续增加，可以在 `03-项目文档/` 下再细分为 `需求`、`接口`、`数据库`、`原型` 等子目录。
- 英文命名和中文命名目前混用，后续可以统一一轮，但建议分批做，避免一次性改动过大影响链接。
