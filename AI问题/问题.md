请用claude code或其它AI编程智能体实现一个c++(或python)程序，它的功能为整理c++代码格式，格式规范要求为：  
- 在变量的定义或声明、函数的形参等情形中，引用和指针要靠近变量名，而不是靠近类型。比如int *A,double &A;  
- 逗号作为分隔符时，比如定义多个变量、分隔函数的多个参数、类构造函数中使用等情况时，逗号后面不要加空格。比如func(int a,int b);  
- 分号作为分隔符时，也有同样的情况，比如for (int i = 0; i < 10; ++i)应该修改为for (int i = 0;i < 10;++i)  
- 当函数体很简短时，去掉函数体大括号内部的首尾空格。比如{ return true; }应该写成{return true;}  
- if,for,while等也需要去掉括号内部的首尾空格，比如for ( int i = 0; i < 10; ++i )要修改为for (int i = 0;i < 10;++i)  
- if,for,while等和后面的括号之间要使用空格，比如if (true);for (int i = 0;i < 10;++i)  
代码实现后，执行方法应该为：  
./codeformat filename  
执行完后将生成新的文件，名字仍然为filename，而旧文件备份为filename.bak.  
最关键需要注意的问题是，怎样验证codeformat的代码正确性，怎样保证filename经过代码整理格式后不会出错。
