## 1. 安装

### Windows

在桌面右键 → 打开 PowerShell，执行一键安装命令：

```powershell
powershell -c "irm https://pi.dev/install.ps1 | iex"
```

- 未安装 Node.js 时按 `y` 回车安装。
- 未安装 Git 时，建议选 `w` 让 Pi 自动安装 Git Bash。
- 安装完成后关闭窗口，重新打开终端输入 `pi` 启动。

### macOS

打开终端，执行：

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

## 2. 配置模型

启动 Pi 后输入 `/login`，提供两种方式：

| 方式         | 说明                                                  |
| ------------ | ----------------------------------------------------- |
| **API Key**  | 支持 40+ 家模型供应商（如 DeepSeek），输入 key 即可   |
| **模型订阅** | `sign in with account`，浏览器登录（如 OpenAI Codex） |

### 常用命令

- `/model`：切换模型
- `Shift + Tab`：切换思考强度
- `Control + L`：打开模型选择器

## 3. 基础操作

- 在项目文件夹内启动 Pi，指令生成的代码会写入该文件夹。
- **多行输入**：`Shift + 回车` 换行；或按 `Control + G` 打开记事本编辑提示词。

### 状态栏信息（最底部一行）

- `↑` 输入 Token / `↓` 输出 Token
- `R` Cache Read（缓存命中 Token）
- `CH` Cache Hit Rate（最近一次请求的缓存命中率）
- 预估成本（`sub` 表示订阅，成本仅供参考）
- 上下文占用百分比 / 模型总上下文窗口
- `auto` 上下文自动压缩机制
- 模型提供商、模型名、思考强度

### 运行命令

- `!命令`：在对话窗口临时运行命令（AI 可看到结果）
- `!!命令`：运行命令但 **AI 不可见**
- 例如：`!npm run dev`

### 与 AI 沟通方式

- **粘贴截图**：Windows `Alt + V`，Mac `Control + V`
- **@ 引用文件**：输入 `@` 选择文件或目录（如 `src/main`）

## 4. 指令追加（Steering / Follow-up）

| 方式                  | 快捷键                               | 含义                       |
| --------------------- | ------------------------------------ | -------------------------- |
| **Steering**（引导）  | 直接回车                             | 立即干预 AI 当前执行方向   |
| **Follow-up**（排队） | `Alt + 回车`（Mac：`Option + 回车`） | 等 AI 完成本轮工作后再执行 |

- 修改已排队的指令：`Alt + ↑` 取回编辑，再 `Alt + 回车` 重新入队。

### 实现原理

- **内层循环**：调用模型 → 调用工具 → 返回结果 → 判断是否完成；新循环会注入 Steering 消息。
- **外层循环**：处理 Follow-up 消息，待内层完成后继续工作。

### 非交互模式（一次性 CLI）

```bash
pi -p "查找今天天气并写入桌面 weather.txt"
```

后台静默执行，适合当作一次性 CLI 命令。

## 5. 会话管理与对话树

- **Session**：连续对话记录的单元。
- `/new`：新建 Session（清空上下文）。
- `pi -c`：从最近一次 Session 继续。
- `pi -r`：挑选某个 Session 继续。

### 对话树（/tree）

- `/tree`：进入对话树，选择节点回退历史状态。
- 可基于历史状态创建分支做不同尝试。
- **注意**：对话树只能回退对话历史，**不能回退代码**，回退代码需配合 Git。

### 回退总结选项

回退历史时提供 3 个选项：

1. **不总结**：彻底抛弃该段历史。
2. **总结**：让 AI 总结被丢弃的分支（仅当前分支，不包含其他分支）。
3. **自定义总结**：告诉 AI 如何总结。

查看总结：`Control + O`

### 其他会话命令

| 命令       | 作用                                                         |
| ---------- | ------------------------------------------------------------ |
| `/clone`   | 完整复制当前 Session 为新的 Session                          |
| `/fork`    | 选择某对话节点，基于该节点复制出新 Session（仅携带之前历史） |
| `/compact` | 手动触发上下文压缩，释放空间、提高专注度                     |

> 经验：**清空好于压缩**。任务完成后建议直接 `/new` 新开 Session。

## 6. 工具设计与插件扩展

### 核心工具（仅 4 个）

Read（读文件）、Write（写文件）、Edit（改文件）、Bash（运行命令）。

- 设计理念：最小工具集覆盖绝大多数编程任务，Bash 是万能工具（find / grep / ls 等）。
- **没有** MCP、SubAgent、Plan Mode、Todo、btw —— 保持核心干净。

### 插件安装

从 Pi 官网 `package` 列表查找插件，复制一键安装命令。

- 全局安装：直接执行安装命令。
- 项目级安装：命令后加 `-l`（local），安装到 `.pi` 文件夹。
- 卸载：把命令中的 `install` 改为 `uninstall`。

### 常用插件

| 插件                   | 功能                                                         |
| ---------------------- | ------------------------------------------------------------ |
| `pi-web-access`        | 联网搜索（零配置，接入 Exa MCP，无需 API key）               |
| `pi-subagents`         | 并行运行多个子代理（`/pi-subagents`）                        |
| `pi-mcp-adapter`       | 增加 MCP 功能（自动读取 `.mcp.json`）                        |
| `btw`                  | 旁路对话（`/btw` 提问，不打断主对话，`Control+C` 退出）      |
| `plan-mode`            | 计划模式（`/plan-mode`，先生成计划到 PLAN.md，确认后再执行） |
| `pi-goal`              | Goal 模式（`/goal`，多轮次朝固定目标迭代执行）               |
| `pi-dynamic-workflows` | 动态工作流（`workflows` 触发，`/workflows` 查看后台）        |
| 即时通信（wechat）     | 连接手机（`/wechat login` 扫码，`/wechat start` 启动）       |

## 7. Agent Skills 配置与使用

- 遵循标准 Skills 协议。
- 项目级路径：`项目目录/.agents/skills/`
- 全局路径：`用户目录/.agents/skills/`（Windows：`C:\Users\用户名\.agents`；Mac：`~/.agents`）

### 安装方式

1. 下载技能源码 zip，将 `skills` 目录复制到上述路径（内含 `SKILL.md`）。
2. 或将提示词发给 AI 让 AI 自动安装。

### 示例技能

- **Playwright CLI**：浏览器自动化（先装 Playwright CLI 工具本体，再装配套 Skill）。
- **Markdown Converter**：任意格式文档转 Markdown（需 `uvx`，缺失时让 AI 安装 uv）。
- **Edge TTS**：文本转语音（零成本，无需 API key）。

> 技能获取渠道：GitHub、SkillHub。

## 8. Web UI 安装与使用

- 社区 Web UI 项目（如 star 最高的项目），用 npx 命令安装，启动后自动打开网页版界面。

### 主要功能

- 左上角：切换项目 / 自定义路径。
- 左下角：文件浏览器、模型配置（添加 provider，如 Kimi）、技能与插件管理（区分 project / global，可开关）。
- 中央：对话面板，支持斜线命令、`@` 文件、截图 `Control+V`、调整思考强度。
- 显示输入/输出 Token 与预估花费。

### 重启命令

关闭浏览器后运行启动命令可重新打开 Web UI。

## 9. 跨 Session 记忆

### 项目级 AGENTS.md

- 在项目根目录创建 `AGENTS.md`，每次对话自动作为上下文带入。
- 可手动编写，也可让 AI 通读项目后自动生成。

### 全局 AGENTS.md

- 路径：`C:\Users\用户名\.pi\agent\AGENTS.md`（Mac：`~/.pi/agent/AGENTS.md`）
- 对电脑上所有项目生效。

### 追加系统提示词 APPEND_SYSTEM.md

- 全局配置目录新增 `APPEND_SYSTEM.md`，内容直接追加到系统提示词，优先级更高、效果更强。
- 一般场景建议优先用 `AGENTS.md`。

## 10. 安全机制

- Pi 安全机制极简：仅在陌生目录（含插件/Skill）启动时询问是否信任加载。
- 运行后**无任何安全限制**，永远最高权限，编辑文件、执行命令均自动执行，无沙箱机制（开发者有意为之）。

### 提升安全性的方案

1. **沙箱运行**：使用 WSL、Hyper-V 虚拟机、Docker 容器等隔离环境，损坏后重建即可。
2. **权限插件**：如 `pi-permission-system`，敏感操作前弹窗审批（类似 Claude Code 权限系统，会拖慢效率，按需选择）。

## 11. DIY 定制插件

Pi 开放大量接口，可自由定制模型、工具系统、会话管理、UI 等。

- 插件本身是 TS 文件，存放于 `项目目录/.pi/extensions/`（项目级）或全局配置目录 `~/.pi/agent/`（全局级）。
- **Pi 能自己给自己写插件**，只需向 AI 描述需求。

### 示例

1. **定制 UI**：根据 IP 查地理坐标 → 查天气 → 展示到对话窗口上方。
2. **权限保护**：禁止 AI 读取 `.env` 文件。
3. **删除确认**：执行 `rm` 删除命令前弹窗询问。

### 操作流程

- 让 AI 编写插件 → `/reload` 重新加载激活。
- 项目级插件复制 `extensions` 文件夹到全局配置目录即可全局生效。

## 12. 源代码架构与 SDK 集成

### 核心包（packages 目录）

| 包             | 职责                                                       |
| -------------- | ---------------------------------------------------------- |
| `ai`           | 模型调用，统一多厂商为相同接口                             |
| `agent`        | Agent Loop 双层循环机制                                    |
| `coding-agent` | 编程功能实现（四个基础工具、系统提示词、Skills、插件机制） |
| `tui`          | 命令行界面功能                                             |

### SDK 集成

- **Pi AI SDK**：`npm install` 后引用 `createModel`，可接入任意模型。
- **Pi Coding Agent SDK**：`npm install` 后创建 Session 即可开启任务，获得开箱即用的 Agent。
