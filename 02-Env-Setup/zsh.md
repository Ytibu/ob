## oy-my-zsh
```zsh
# 下载zsh
sudo apt install zsh
# 下载配置
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
# 编辑 配置文件 
vim .zshrc
```


## fast fetch
```zsh
# 下载
sudo apt install fastfetch
# 生成可编辑的配置文件
fastfetch --gen-config
# 将fastfetch命令写进环境配置中.zshrc或.bashrc
```
