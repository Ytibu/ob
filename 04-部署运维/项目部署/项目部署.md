## Nginx命令

源代码：

启动: `sbin/nginx`  

停止: `sbin/nginx -s quit`  

重新加载: `sbin/nginx -s reload`  

## 软件安装

### JDK安装

1) 将jdk的二进制文件上传到linux系统上

2) 解压安装包: `tar -zxvf jdk-17.0.10_linux-x64_bin.targ.gz -C /usr/local`

3) 配置环境变量: 编辑`/etc/profile`文件，文件末尾添加配置

```
export JAVA_HOME=/usr/local/jdk-17.0.10
```

```
		export PATH=$JAVA_HOME/bin:$PATH
```

 

4) 重新加载profile文件: `source /etc/profile`

 5) 检查是否安装成功: `java --version`

## 前端项目部署

1) 上传静态资源到`/usr/local/nginx/html/`目录中  

2) 在`/usr/local/conf/nginx.conf`中配置代理  

3) 在`/usr/local/nginx/`中启动nginx  

## 后端项目部署

1) 执行Maven中的package生命周期，并得到target/下的xxx.jar包  

2) 在服务器`/usr/local/`下创建项目目录，例如xxxx-app，将jar包上传到服务器的/usr/local/xxxx-app  

3) 运行命令 `java -jar xxx.jar`  

4) 环境变量配置: 编辑`/etc/profile`文件，文件末尾添加`export PATH=/xx/xx/x`，保存并`source /etc/profile`  

5) 项目后台运行并设置日志输出文件: 执行`nohup java -jar xxx.jar &> xxx.log &`，查看进程`ps -ef | grep xxx.jar`  

6) 进程关闭: `kill -9 进程号`
