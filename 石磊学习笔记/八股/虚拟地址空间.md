## 描述
32位linux系统下系统分配2^32大小的虚拟地址空间即4GB：3GB用户空间、1GB内核空间
- 在0x00000000到0x08048000：不可访问，这就是为何不能访问或操作空指针
-  `.text`代码段 ，代码文本` .rodata` 只读数据段， char 指针 = "hello worlld"。
- `.data` 数据段， 初始化数据：初始化的全局和静态变量(全局静态变量和局部静态变量)
- `.bss` 数据段，未初始化数据(系统会初始化 data=0)：未始化的全局和静态变量
- `.heap` 堆空间：高地址向低地址加载
- `*.dll/*.so` 加载的共享库
- `stack` 栈空间：高地址向低地址加载，局部变量(局部静态变量在.data或.bss) 
- `命令函参数和环境变量`
- 内核空间：ZONE_DMA、ZONE_NORMAL、ZONE_HIGHMEM，多个进程的用户地址空间私有，但是内核空间共享

## 可视化
```txt
4GB (0xFFFFFFFF) +------------------+
                  |                  |
                  |    内核空间       |
                  |   (1GB - 2GB)    |
                  |                  |
3GB/2GB (0xC0000000/0x80000000) +------------------+
                  |                  |
                  |      栈段         |  <- 局部变量、函数调用
                  |  (向下增长)       |
                  |                  |
                  |      空洞         |  <- 预留区域
                  |                  |
                  |      堆段         |  <- malloc/new动态分配
                  |  (向上增长)       |
                  |                  |
                  |    BSS段          |  <- 未初始化全局/静态变量
                  |                  |
                  |    数据段         |  <- 已初始化全局/静态变量
                  |                  |
                  |    代码段/文本段   |  <- 程序指令(只读)
                  |                  |
0x08048000/0x400000 +------------------+
                  |                  |
                  |      保留区       |  <- NULL指针保护
                  |                  |
0 (0x00000000)   +------------------+
```
