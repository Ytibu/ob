C++ 源代码从编写到可执行文件，通常经历 **4 个阶段**：

```
源代码(.cpp/.h) → 预处理 → 编译 → 汇编 → 链接 → 可执行文件
```

## 1. 预处理 (Preprocessing)

**处理以 `#` 开头的指令**，生成纯 C++ 代码（无宏、无头文件）。

| 指令 | 作用 | 示例 |
|------|------|------|
| `#include` | 头文件内容插入 | `#include <iostream>` |
| `#define` | 宏展开 | `#define PI 3.14` |
| `#ifdef` / `#ifndef` | 条件编译 | 头文件保护符 |
| `#pragma` | 编译器特定指令 | `#pragma once` |

```cpp
// 源代码
#define MAX 100
int a = MAX;

// 预处理后
int a = 100;
```

**命令**：
```bash
g++ -E main.cpp -o main.i   # 生成 .i 预处理文件
```

---

## 2. 编译 (Compilation)

**将预处理后的代码 → 汇编代码**（与平台相关）。

- 语法分析、词法分析
- 语义检查、类型检查
- 代码优化

```cpp
// 输入: main.i
int add(int x, int y) {
    return x + y;
}

// 输出: main.s (x86-64 汇编)
add:
    pushq   %rbp
    movq    %rsp, %rbp
    movl    %edi, -4(%rbp)
    movl    %esi, -8(%rbp)
    movl    -4(%rbp), %edx
    movl    -8(%rbp), %eax
    addl    %edx, %eax
    popq    %rbp
    ret
```

**命令**：
```bash
g++ -S main.i -o main.s   # 生成汇编文件
```

---

## 3. 汇编 (Assembly)

**将汇编代码 → 机器码（目标文件 `.o` / `.obj`）**。

- 生成 **可重定位目标文件**
- 包含机器指令、数据段、符号表（未解析的外部符号）

**命令**：
```bash
g++ -c main.s -o main.o   # 生成目标文件
```

---

## 4. 链接 (Linking)

**合并多个目标文件 + 库 → 可执行文件**。  
**步骤一：** 所有.o文件段的合并，符号表合并后，进行符号解析  
**步骤二：** 符号的重定位  


- **符号解析**：匹配函数/变量的定义与引用
- **重定位**：分配最终内存地址，修改代码中的地址引用
- **静态链接**：库代码直接拷贝进可执行文件（`.a` / `.lib`）
- **动态链接**：运行时加载共享库（`.so` / `.dll`）

```bash
g++ main.o helper.o -o program   # 链接两个目标文件
```

---

## 完整示例（命令行）

```bash
# 一次性完成所有步骤
g++ main.cpp -o program

# 分步查看中间结果
g++ -E main.cpp -o main.i      # 预处理
g++ -S main.i -o main.s        # 编译
g++ -c main.s -o main.o        # 汇编
g++ main.o -o program          # 链接
```

---

## 常见编译选项

| 选项 | 作用 |
|------|------|
| `-E` | 只做预处理 |
| `-S` | 生成汇编代码 |
| `-c` | 生成目标文件，不链接 |
| `-o` | 指定输出文件名 |
| `-g` | 生成调试信息 |
| `-O2` | 优化级别 |
| `-I` | 添加头文件搜索路径 |
| `-L` | 添加库搜索路径 |
| `-l` | 链接指定库 |

## 头文件保护符的工作原理

```cpp
// utils.h
#ifndef UTILS_H
#define UTILS_H
int add(int a, int b);
#endif
```

预处理时，条件编译指令确保头文件内容只被包含一次，避免重复定义错误。
