## 函数默认值
- 默认值 从右往左赋值(从右往左压栈)
- 定义可以给定义形参默认值，声明也可以定义形参默认值
- 形参默认值只能赋值一次
- 调用效率：直接生成的汇编没有差异，但是理论存在

## inline关键字
- 在函数调用点直接把函数展开，编译过程中就没有函数调用的开销（函数的调用有开销）
- inline只是建议编译器把这个函数处理成内联函数，不是所有的函数，例如递归
- inline只出现在rerlease版本，debug版本inline不起作用
- 不会在符号表中生成函数符号

## 函数重载
- C++支持函数重载，C语言不支持函数重载
- 函数重载：函数名相同，参数列表不同(个数、类型、顺序)，返回值不作为参量(即返回值不同，其他相同是语法错误)
- 作用域：就近的函数声明重载后，只能使用该作用域内的重载函数
- const和volatile会因影响形参类型
- 函数重载属于静态多态
- C++与C代码之间相互调用：
```C

# C++调用C语言函数：在C++代码中声明函数并
extern "C"{
  int sum_c(int a, int b);
}

# C语言调用C++函数：在C++中实现函数并
extrn "C"{
  int sum_cpp(int a, int b)
  {
   return a + b;
  }
}
```

## const关键字
- 编译方式：在C中，const当作一个变量来编译生成指令。C++中，出现const常量的位置， 都被常量的初始化替换了
- C语言中：可以不用初始化，不叫作常量，可以被修改，叫做常变量
- C++中：必须初始化，不能作为左值，初始化后不能被修改
- C++中，初始值是立即数就是常量，初始值是变量就是常变量
- C语言中：const 可以不初始化，不能被修改，不是编译时常量，不能用于定义数组大小
- C++中：const 必须初始化，不能被修改，是编译时常量，可以用于定义数组大小
- 总结：C语言中const是只读变量，无法值替换。C++中const是常量，可以值替换
```C
# C
const int size = 10;
int arr[size];  // 错误：C 语言中 const 变量不是真正的常量,不能用于定义数组大小

# C++
const int size = 10;
int arr[size];  // 正确：C++ 中 const 是编译时常量,可以用于定义数组大小
```

## const与一级指针
- `const 修饰的量`不能作为左值：禁止直接修改const 修饰的量的值
- 不能把`const 修饰的量`的地址泄露给一个普通的指针或普通的引用变量：禁止间接修改`const 修饰的量`的值
```C
const int a = 10;
int *p = &a;

// a = 20; // 错误，禁止直接修改值
// *p = 30; // 错误，禁止将地址泄露给一个普通指针或普通引用
```
- const 与 一级指针：c++规范，const修饰的是离他最近的类型
```C
const int *p;  // 修饰的是int 
# 不能：*p = 10, 可以：p = &a
# 可以指向不同的int类型内存，但是不能修改内存的值
int cont* p; // 同上,修饰的是int

int *const p = &b;  //修饰的是 int*
# 不能： p = &a, 可以：*p = 20
# 不能修改指向的内存，但是可以修改内存的值

const int *const p = &a;  // 修饰 int * 和 p
# 不能 *p = 20, 不能：p = &b
```
- const与指针的类型转换 int* 可以转 const int*， 但const int* 不能转 int*
- const右侧没有指针，是不参与类型的
```C
int a = 10;
int *p1 = &a;
const int *p2 = &a;  // const int* <= int*
int *const p3 = &a;  // int* <= int*
int* p4 = p3;        // int* <= int*
```

## const与二级指针
- `int **` 不能与 `const int**` 转换
- `int* const*`不能转换为 `int **`
- `int **` 可以转换为 `int* const*`


## 左值引用与右值引用

- 引用与指针：
	1. 引用必须初始化，指针可以不初始化；
	2. 引用只有一级引用，指针可以有多级指针；
	3. 引用与指针汇编指令一样，引用和指针修改指向内存的值汇编指令一样
- 左值引用与右值引用
	1. const修饰可以引用右值(右值没内存、没名字)：cont int &a = 20;（产生临时量，保存临时量）
	2. 右值引用本身是左值，不能用`右值引用`本身来引用左值
	```C
	const int &a = 200; 正确：但是实际是 产生临时量，保存临时量
	int b = 100;
	int &&c = b; 错误：右值引用不能引用左值，因为本身就是左值
	```
