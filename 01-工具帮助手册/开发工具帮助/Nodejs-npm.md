## 常用命令
```bash
# 查看校验
node -v
npm -v
# 全局安装
npm install -g @openai/codex
# 本地安装
npm install @openai/codex
# 卸载
npm uninstall express
# 更新
npm update express
# 搜索
npm search express
# 查看全局安装
npm list -g
npm list -g --depth=0
```
