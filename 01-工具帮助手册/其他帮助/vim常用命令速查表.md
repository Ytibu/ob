# Vim 常用命令速查表

适合新手快速查看的基础版，只包含最常用的操作。

## 一、模式说明

- `普通模式`：移动光标、删除、复制、粘贴等
- `插入模式`：输入文本
- `命令模式`：输入保存、退出、查找等命令

## 二、进入与退出插入模式

| 命令 | 说明 |
| --- | --- |
| `i` | 在光标前进入插入模式 |
| `a` | 在光标后进入插入模式 |
| `o` | 在当前行下方新开一行并进入插入模式 |
| `Esc` | 退出插入模式，回到普通模式 |

## 三、保存与退出

| 命令 | 说明 |
| --- | --- |
| `:w` | 保存文件 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:q!` | 不保存强制退出 |

## 四、光标移动

| 命令 | 说明 |
| --- | --- |
| `h` | 左移 |
| `j` | 下移 |
| `k` | 上移 |
| `l` | 右移 |
| `gg` | 跳到文件开头 |
| `G` | 跳到文件结尾 |
| `0` | 跳到当前行开头 |
| `$` | 跳到当前行结尾 |

## 五、删除命令

| 命令 | 说明 |
| --- | --- |
| `x` | 删除当前字符 |
| `dd` | 删除当前整行 |
| `D` | 删除光标到行尾 |
| `dG` | 删除当前行到文件结尾 |
| `ggdG` | 删除整个文件内容 |

## 六、复制与粘贴

| 命令 | 说明 |
| --- | --- |
| `yy` | 复制当前行 |
| `p` | 在当前行下方粘贴 |
| `P` | 在当前行上方粘贴 |

## 七、撤销与重做

| 命令 | 说明 |
| --- | --- |
| `u` | 撤销上一步 |
| `Ctrl + r` | 重做 |

## 八、查找

| 命令 | 说明 |
| --- | --- |
| `/关键字` | 向下查找 |
| `?关键字` | 向上查找 |
| `n` | 跳到下一个匹配 |
| `N` | 跳到上一个匹配 |

## 九、可视模式

| 命令 | 说明 |
| --- | --- |
| `v` | 进入字符可视模式 |
| `V` | 进入行可视模式 |
| `d` | 删除选中内容 |
| `y` | 复制选中内容 |

## 十、最常用组合

| 操作 | 命令 |
| --- | --- |
| 插入文字 | `i` |
| 退出插入 | `Esc` |
| 删除一行 | `dd` |
| 复制一行 | `yy` |
| 粘贴 | `p` |
| 撤销 | `u` |
| 保存退出 | `:wq` |
| 强制退出不保存 | `:q!` |
| 删除全文 | `ggdG` |

## 十一、常见使用流程

```bash
vim 文件名
```

1. 按 `i` 进入插入模式
2. 输入内容
3. 按 `Esc` 返回普通模式
4. 输入 `:wq` 保存并退出

## 十二、新手建议先记住这些

- `i`
- `Esc`
- `dd`
- `yy`
- `p`
- `u`
- `:wq`
- `:q!`
- `ggdG`
